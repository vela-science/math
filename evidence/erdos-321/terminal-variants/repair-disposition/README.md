# Erdős 321 terminal bridge disposition

This package closes the bounded repair question without claiming an implication
that the retained sources do not prove.

The terminal theorem and fixed variants use different exact source trees,
toolchains, coordinate definitions, hypotheses, and constants. The candidate
index substitutions `k = d + 2` and `r = d + 2` align the displayed product
endpoints only. Neither retained source supplies a theorem connecting its real
iterated-log tower to the fixed source's `Nat.log` hypotheses or products.

The disposition is therefore `unsupported_by_retained_basis`. This is not a
proof that no bridge exists and not a claim that either theorem is false. It is
an exact reason to keep both terminal-to-fixed relations unresolved until a
rooted cross-source port and explicit bridge theorem exist.

Build and check without network access:

```bash
python3 -B evidence/erdos-321/terminal-variants/repair-disposition/build.py \
  --lean-proofs-repo ../lean-proofs \
  --formal-conjectures-repo ../formal-conjectures --check
python3 -B evidence/erdos-321/terminal-variants/repair-disposition/test_build.py
```

The record has no authority effect by itself. Vela Submission, Verification,
Decision, and replay remain separate.

`correction-remap.v1.json` records the later completed loop without rewriting
the historical cold-reader packet. One producer-context AI review is retained
as complementary evidence; a separately attributed OpenAI Codex agent review
satisfies the declared independence requirement. An attributed agent Decision
then accepted the bounded negative scope Claim under Repository authority.
Both scientific relations remain unresolved, while the narrower investigation
obligation is closed as `unsupported_by_retained_basis`.

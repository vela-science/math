# Bounded correction validation

This directory is prospective Result Runner validation only. It contains no
provider request, canary, campaign cell, scientific conversion, or Vela
authority action.

`proof-attempt-1/` permanently retains the first container check. It failed
because its submitted file imported a source module that was not available in
the pinned image's built project graph. The failure remains classified
`invalid`; it was not overwritten or upgraded.

`proof/` is the corrected source-native check against an already-built exact
Formal Conjectures source declaration. Its closed Result, statement, submitted
Lean bytes, audit preimage, output streams, OLean, and receipt replay as one
root-bound verification. `preflight/` independently retains the successful
network-disabled exact-source Lean/lake runtime check.

`VALIDATION.json` binds the reviewer finding, runtime/image/source identities,
the retained failed and passing receipts, and offline gate counts. Declared
elapsed seconds and absolute host mount paths in the receipts are observational;
the submitted/result/source/output bytes and deterministic proof roots are exact.

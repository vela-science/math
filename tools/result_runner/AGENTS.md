# Result Runner boundary

This directory owns candidate execution mechanics, never scientific authority.

- Run Codex only from a real Git repository.
- Keep the supplied source repository and OAuth bytes read-only.
- Keep output bounded and verify source commit, tree, archive digest, and clean
  status before and after execution.
- The disposable Vela recorder must always reject its qualification Proposal,
  delete its authority key, and report `scientific_state_changed: false`.
- Never add an acceptance path, canonical Repository credential, provider key,
  automatic outreach, or Protocol object here.
- Convert an operational failure into a focused regression test. Do not copy
  the runner into an experiment or add another preregistration layer.

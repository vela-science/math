# External review packet

This packet is ready for, but does not manufacture, one outside evaluation.

Ask an evaluator with no Vela authority role to:

1. open the primary-source locators in `audit.json` and `candidates.json`;
2. check the five retained status/scope summaries without relying on copied
   external body text;
3. inspect `comparison.json` and mark each finding supported, overstated, or
   unsupported;
4. clone this exact Math commit without external providers, run
   `python3 evaluate.py verify`, and identify what remains readable;
5. state whether the evidence supports these separate claims:
   - FAR is better at discovery and allocation;
   - ProbXiv already separates evidence modalities and limitations;
   - Vela adds an attributable Decision/Event/Standing and correction boundary;
   - none of the external candidate Results has been admitted by Vela.

The evaluator should disclose employer/affiliation, prior involvement with
FAR, ProbXiv, Vela, and the source problems, shared tools or model providers,
and whether the review was compensated. A different person is not by itself
independent.

Return a signed or ordinary Git document naming this repository commit, the
candidate-set root printed by `evaluate.py verify`, disputed cells, and any
missing primary evidence. That document is external evaluation evidence only;
it is not a Verification Record, Repository Decision, Event, or Standing.
